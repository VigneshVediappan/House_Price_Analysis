# House Price Analysis

## Aim
To analyze house area, bedrooms, and prices using R programming.

## Description
This project analyzes a small dataset of houses. It calculates price per square foot, average house price, average area, and identifies the most expensive house.

## Technologies Used
- R Programming
- Data Frames
- Basic Data Analysis

## Features
- Stores house details
- Calculates price per square foot
- Calculates average house price
- Calculates average area
- Finds the most expensive house

## How to Run
1. Open `05_House_Price_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the results in the console.

## Result
The program successfully analyzes house price data and provides useful property statistics.
